Βασικές έννοιες

  • Το model file size δεν είναι όλο το runtime memory· context και inference buffers καταναλώνουν επιπλέον RAM.
  • Μικρότερα quantized models μπορεί να είναι πρακτικά offline, αλλά accuracy και languages διαφέρουν.
  • Long inference μπορεί να προκαλέσει throttling και battery drain ακόμα αν το model φορτώνει.

Κανόνας απόφασης

Κράτησε αρκετή free RAM για Android και σταμάτησε tests με persistent heat, swapping ή app instability.
