2 λεπτά ανάγνωσηςAndroid · Termux

Η ακαδημία διαχωρίζει αυστηρά τους ρόλους: η ιστοσελίδα εξηγεί τη μέθοδο· το Termux εκτελεί την εργασία.

Τυπικός κύκλος lab

python Smartphone-Academy.py list --practical
python Smartphone-Academy.py prepare environment-inventory
cd ~/.dedsec-smartphone-academy/workspaces/environment-inventory
python Smartphone-Academy.py check environment-inventory
python Smartphone-Academy.py complete environment-inventory
python Smartphone-Academy.py status

Πού αποθηκεύονται τα αρχεία

  • $HOME: ιδιωτικό Termux home και προτεινόμενος χώρος ακαδημίας.
  • ~/storage/shared: κοινόχρηστο Android storage, μόνο μετά από ρητή άδεια.
  • ~/.dedsec-smartphone-academy: τοπική πρόοδος και παραγόμενα workspaces.

Πριν από κάθε εντολή

  1. Επιβεβαίωσε το path με pwd.
  2. Διάβασε την εντολή και κατανόησε κάθε option.
  3. Κράτησε τα αρχικά τεκμήρια αμετάβλητα.
  4. Κατέγραψε περιορισμούς αντί να μαντεύεις.
Καμία εκτέλεση στον browser

Αντέγραψε τις εντολές μόνος σου στο Termux. Έτσι ο εκπαιδευόμενος ελέγχει scope, paths και output.
