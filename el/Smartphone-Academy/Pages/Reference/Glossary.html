Asset

Οτιδήποτε πολύτιμο χρειάζεται προστασία, όπως δεδομένα, λογαριασμοί, συσκευές ή υπηρεσίες.

Authentication

Η επαλήθευση του ποιος ισχυρίζεται ότι είναι ένας χρήστης ή σύστημα.

Authorization

Η απόφαση για το τι επιτρέπεται να προσπελάσει ή να αλλάξει μια ταυτότητα.

Confidentiality

Η διατήρηση πληροφοριών μόνο για εξουσιοδοτημένα άτομα και συστήματα.

Exploit

Κώδικας ή τεχνική που χρησιμοποιεί ευπάθεια για μη προβλεπόμενη συμπεριφορά.

Hash

Αποτέλεσμα σταθερού μήκους από δεδομένα, χρήσιμο σε ελέγχους ακεραιότητας και σχεδιασμό αποθήκευσης passwords.

Integrity

Η προστασία δεδομένων από μη εξουσιοδοτημένη ή τυχαία αλλαγή.

Least privilege

Η παροχή μόνο των δικαιωμάτων που απαιτούνται για μια εργασία.

Payload

Το τμήμα μιας λειτουργίας που εκτελεί την επιθυμητή ενέργεια μετά την παράδοση ή εκτέλεση.

Phishing

Κοινωνική μηχανική που προσπαθεί να εξαπατήσει κάποιον ώστε να δώσει πληροφορίες ή να κάνει μη ασφαλή ενέργεια.

Threat

Πιθανή αιτία βλάβης σε σύστημα ή asset.

Vulnerability

Αδυναμία που μπορεί να επηρεάσει εμπιστευτικότητα, ακεραιότητα ή διαθεσιμότητα.
