35 · Custom ROMs και Android System Modding Android devices

Προετοίμασε αξιόπιστη σύνδεση υπολογιστή-κινητού πριν αλλάξεις bootloader ή partitions.

Χρήση επίσημων εργαλείων

Κατέβασε Android SDK Platform Tools από Android Developers ή χρησιμοποίησε το package του supported λειτουργικού σου. Απόφυγε random “minimal ADB” archives.

Έλεγξε version με `adb version` και `fastboot --version`, μετά δοκίμασε data cable και direct USB port.

Connection checks

Με το Android ενεργό, εξουσιοδότησε τον υπολογιστή και επιβεβαίωσε serial με `adb devices`. Κάνε reboot στον bootloader μόνο αφού λειτουργεί το κανονικό ADB.

Σε bootloader mode, επιβεβαίωσε serial με `fastboot devices`. Μην κάνεις flash μέχρι η σύνδεση να είναι σταθερή μετά από reconnects.

Συνηθισμένες αποτυχίες

Charge-only cables, USB hubs, missing drivers, virtual machines, βρώμικες θύρες και background tools μπορούν να διακόψουν flashing. Άλλαζε μία μεταβλητή κάθε φορά.

Κρίσιμο όριο ασφάλειας

Το unlocking και flashing μπορεί να διαγράψει δεδομένα, να μειώσει την ασφάλεια, να απενεργοποιήσει protected services ή να κάνει τη συσκευή unbootable. Χρησιμοποίησε μόνο δική σου συσκευή, exact model-specific instructions και tested stock restore path.
