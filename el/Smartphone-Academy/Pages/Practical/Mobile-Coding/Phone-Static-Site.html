Δημιουργία και Validation Static Site στο Termux

Δημιούργησε μικρό bilingual responsive website και δοκίμασέ το σε localhost και repository subpath.

3 ώρεςAndroid · Termux

Αποστολή

Δημιούργησε μικρό bilingual responsive website και δοκίμασέ το σε localhost και repository subpath.

Απαιτούμενη εργασία

  1. Χρησιμοποίησε semantic HTML και accessible controls
  2. Κράτησε assets relative στο project
  3. Δοκίμασε 320px και desktop layouts
  4. Κάνε validation όλων των local links

Evidence που πρέπει να παραχθεί

Site folder, local server command και link-validation report.

Έλεγχοι ποιότητας

Το αποτέλεσμα πρέπει να αναφέρει πηγές, να ξεχωρίζει observation από assumption, να διατηρεί originals και να εξηγεί limitations.

Προετοιμασία lab

Εκτέλεσε αυτές τις εντολές μέσα στον φάκελο Smartphone Academy στο Termux.

python Smartphone-Academy.py prepare phone-static-site
cd ~/.dedsec-smartphone-academy/workspaces/phone-static-site
python Smartphone-Academy.py check phone-static-site
python Smartphone-Academy.py complete phone-static-site

Χρησιμοποίησε μόνο τα supplied fictional samples ή δεδομένα της δικής σου συσκευής.
