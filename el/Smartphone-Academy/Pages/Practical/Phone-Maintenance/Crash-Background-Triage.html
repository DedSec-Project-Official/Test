Αποστολή

Χρησιμοποίησε supplied event records για διάκριση app bugs, low memory, battery restrictions και storage pressure.

Απαιτούμενη εργασία

  1. Ομαδοποίησε failures ανά app και timestamp.
  2. Συσχέτισε memory, storage και battery-policy events.
  3. Κατάταξε hypotheses βάσει evidence.
  4. Δημιούργησε minimal change-and-retest plan.

Evidence που πρέπει να παραχθεί

Cause matrix με evidence, confidence και reversible test steps.

Έλεγχοι ποιότητας

Το αποτέλεσμα πρέπει να αναφέρει source data, να ξεχωρίζει observation από assumption, να διατηρεί τα supplied originals και να εξηγεί κάθε limitation ή αβέβαιο conclusion.

Προετοιμασία lab

Εκτέλεσε αυτές τις εντολές μέσα στον φάκελο Smartphone Academy στο Termux.

python Smartphone-Academy.py prepare crash-background-triage
cd ~/.dedsec-smartphone-academy/workspaces/crash-background-triage
python Smartphone-Academy.py check crash-background-triage
python Smartphone-Academy.py complete crash-background-triage

Τοπικό και αμυντικό

Χρησιμοποίησε μόνο τα supplied fictional samples ή δεδομένα της δικής σου συσκευής που επιλέγεις συνειδητά να ελέγξεις.
