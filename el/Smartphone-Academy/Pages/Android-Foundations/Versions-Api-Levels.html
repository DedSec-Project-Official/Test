Μάθε γιατί η έκδοση Android, το API level, το security patch και το Google Play system update είναι διαφορετικά στοιχεία συμβατότητας.

Βασικές έννοιες

Χρησιμοποίησε αυτά τα σημεία για ακριβές τεχνικό μοντέλο πριν αλλάξεις τη συσκευή.

  • Το API level δείχνει ποιες λειτουργίες πλατφόρμας είναι διαθέσιμες.
  • Το minimum SDK καθορίζει αν επιτρέπεται η εγκατάσταση.
  • Το target SDK επηρεάζει σύγχρονους κανόνες ασφάλειας και λειτουργίας στο background.

Κανόνας απόφασης

Κατέγραψε και τα τέσσερα στοιχεία έκδοσης πριν αποφασίσεις ότι μια εφαρμογή ή ένα αξεσουάρ είναι συμβατό.

Εφάρμοσέ το στο κινητό σου

Κατέγραψε τα στοιχεία συσκευής, την πηγή και το αναμενόμενο αποτέλεσμα. Κάνε μία αναστρέψιμη αλλαγή, παρατήρησε το αποτέλεσμα και κράτησε evidence για επαναφορά.

Επίσημη πηγή

Χρησιμοποίησε την παρακάτω τεκμηρίωση πλατφόρμας για επαλήθευση λεπτομερειών που αλλάζουν ανά έκδοση Android.

  • developer.android.com/guide/topics/manifest/uses-sdk-element
