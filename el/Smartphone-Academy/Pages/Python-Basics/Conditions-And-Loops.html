  • Εφαρμόσεις την έννοια σε ρεαλιστικό παράδειγμα Android, Termux ή τοπικού εργαστηρίου και να ξεχωρίσεις την άμεση παρατήρηση από την ερμηνεία.

Επαγγελματικό Πλαίσιο

Η επαγγελματική εργασία με Python κάνει σαφή τη ροή δεδομένων, τις αλλαγές κατάστασης και τη συμπεριφορά σε αποτυχία. Ένα μικρό σωστό πρόγραμμα με δοκιμές είναι πιο χρήσιμο από μεγάλο script που λειτουργεί μόνο στο ιδανικό σενάριο.

Μέχρι τώρα μάθαμε πώς να αποθηκεύουμε δεδομένα σε μεταβλητές.

Σε αυτό το κεφάλαιο θα μάθουμε πώς ένα πρόγραμμα μπορεί να παίρνει αποφάσεις και να εκτελεί τις ίδιες ενέργειες πολλές φορές χωρίς να γράφουμε τον ίδιο κώδικα ξανά και ξανά.

Conditions (Συνθήκες)

Οι συνθήκες επιτρέπουν στο πρόγραμμα να εκτελεί διαφορετικό κώδικα ανάλογα με μια προϋπόθεση.

Στην Python χρησιμοποιούμε κυρίως:

  • if
  • elif
  • else

Η Εντολή If

Η if εκτελεί τον κώδικα μόνο αν η συνθήκη είναι αληθής.

Παράδειγμα:

is_admin = True

if is_admin:
    print("Access Granted")

Έξοδος:

Access Granted

Η Εντολή Else

Η else εκτελείται όταν η συνθήκη είναι ψευδής.

is_admin = False

if is_admin:
    print("Access Granted")
else:
    print("Access Denied")

Έξοδος:

Access Denied

Η Εντολή Elif

Η elif χρησιμοποιείται όταν θέλουμε να ελέγξουμε περισσότερες από μία συνθήκες.

port = 443

if port == 22:
    print("SSH")
elif port == 80:
    print("HTTP")
elif port == 443:
    print("HTTPS")
else:
    print("Unknown Service")

port = 80

Loops

Τα Loops χρησιμοποιούνται όταν θέλουμε να εκτελέσουμε την ίδια ενέργεια πολλές φορές.

Οι δύο βασικοί τύποι είναι:

  • for
  • while

For Loop

Η for χρησιμοποιείται για να διατρέξουμε μια λίστα ή μια ακολουθία δεδομένων.

ports = [22, 80, 443]

for port in ports:
    print(port)

Έξοδος:

22
80
443

Μπορούμε επίσης να διατρέξουμε λίστες με IP Addresses.

targets = [
    "192.168.1.10",
    "192.168.1.20",
    "192.168.1.30"
]

for target in targets:
    print("Scanning", target)

While Loop

Η while εκτελείται όσο μια συνθήκη παραμένει αληθής.

counter = 1

while counter <= 5:
    print(counter)
    counter += 1

Έξοδος:

1
2
3
4
5

Infinite Loops

Αν η συνθήκη μιας while δεν γίνει ποτέ False, τότε το πρόγραμμα θα εκτελείται για πάντα.

Παράδειγμα:

while True:
    print("Running...")

Προσοχή! Αυτό δημιουργεί ένα Infinite Loop και το πρόγραμμα δεν θα σταματήσει μόνο του.

Conditions & Loops Στο Cybersecurity

Οι συνθήκες και οι επαναλήψεις χρησιμοποιούνται συνεχώς σε εργαλεία Cybersecurity.

Παραδείγματα:

  • Έλεγχος αν ένας host είναι online.
  • Σάρωση πολλών IP Addresses.
  • Έλεγχος αν μια θύρα είναι ανοιχτή.
  • Ανάγνωση πολλών αρχείων log.
  • Αυτοματοποίηση επαναλαμβανόμενων εργασιών.

Επόμενο Κεφάλαιο

Τώρα που μπορούμε να γράψουμε πιο "έξυπνα" προγράμματα, θα μάθουμε πώς να οργανώνουμε τον κώδικά μας χρησιμοποιώντας Functions.

Έλεγχος Ροής Χωρίς Απρόβλεπτη Συμπεριφορά

Μια condition πρέπει να εκφράζει καθαρά το decision που θέλεις να πάρεις. Συνδύασε expressions με and, or και not μόνο όταν η λογική παραμένει ευανάγνωστη. Αν μια σύνθετη συνθήκη δυσκολεύει τον έλεγχο, αποθήκευσε επιμέρους booleans με περιγραφικά names.

Σε loops καθόρισε εκ των προτέρων πότε σταματά η επανάληψη. Το for είναι κατάλληλο όταν επεξεργάζεσαι γνωστή collection, ενώ το while απαιτεί ιδιαίτερη προσοχή στο termination condition. Τα break και continue μπορούν να βοηθήσουν, αλλά υπερβολική χρήση κάνει τη ροή δυσκολότερη στην επαλήθευση.

Για ασφαλές practice χρησιμοποίησε τοπική λίστα από labels ή ports ως δεδομένα και όχι πραγματικό scanning. Έλεγξε τρεις περιπτώσεις: condition True, condition False και empty list. Αυτό δείχνει ότι ο κώδικας χειρίζεται και edge cases αντί να λειτουργεί μόνο στο happy path.

Επαγγελματική Ροή Εργασίας

  1. Διατύπωσε την ερώτηση που προσπαθείς να απαντήσεις για το θέμα «Συνθήκες και Επαναλήψεις» και όρισε τη συσκευή, το αρχείο, την εφαρμογή ή την υπηρεσία που βρίσκεται εντός του πεδίου εργασίας (scope).
  2. Χτίσε το μοντέλο ξεκινώντας από «Conditions (Συνθήκες)» και «Η Εντολή If» και γράψε ποια παρατήρηση θα επιβεβαίωνε κάθε μέρος.
  3. Γράψε το μικρότερο παράδειγμα που δείχνει την έννοια και δοκίμασε κανονικό, κενό και άκυρο input. Κατέγραψε τιμές εισόδου, έξοδο, exceptions, return values, αλλαγές αρχείων, tests και την ακριβή έκδοση Python όπου είναι σχετικό.
  4. Έλεγξε ισχυρισμούς που εξαρτώνται από έκδοση σε πρωτογενή ή επίσημη πηγή και κατέγραψε την έκδοση/ημερομηνία που χρησιμοποίησες.
  5. Γράψε σύντομο συμπέρασμα που ξεχωρίζει παρατηρημένα γεγονότα, ερμηνεία, περιορισμούς και ό,τι παραμένει αβέβαιο.

Έλεγχος Κατανόησης

  1. Με δικά σου λόγια, τι εξηγεί ή τι σε βοηθά να αποφασίσεις το θέμα «Συνθήκες και Επαναλήψεις» και πώς εντάσσεται το Conditions (Συνθήκες) στο μοντέλο;
  2. Ποιος είναι ο κίνδυνος από το εξής: η θεώρηση μίας επιτυχημένης εκτέλεσης ως απόδειξη ότι το πρόγραμμα χειρίζεται σωστά κενά, άκυρα ή απρόβλεπτα inputs; Δώσε συγκεκριμένο παράδειγμα.
  3. Ποια παρατήρηση ή πηγή θα χρησιμοποιούσες για να επαληθεύσεις το μάθημα σε διαφορετική συσκευή ή έκδοση λογισμικού;

Μια ισχυρή απάντηση χρησιμοποιεί τις έννοιες του μαθήματος, κατονομάζει τεκμήρια και δηλώνει τουλάχιστον μία συνθήκη που θα μπορούσε να αλλάξει το συμπέρασμα.

Κριτήριο Ολοκλήρωσης

  • Μπορείς να εξηγήσεις την έννοια χωρίς αντιγραφή και να συνδέσεις τους σημαντικούς όρους με ένα ρεαλιστικό παράδειγμα.
  • Μπορείς να κατονομάσεις το τεκμήριο που θα επιβεβαίωνε ή θα αμφισβητούσε την εξήγησή σου.
  • Μπορείς να εντοπίσεις τουλάχιστον έναν τρόπο αποτυχίας, μία συνθήκη συμβατότητας, ένα όριο ασφάλειας ή μία πηγή αβεβαιότητας.
  • Γνωρίζεις ποια λεπτομέρεια που εξαρτάται από έκδοση χρειάζεται πρωτογενή ή επίσημη πηγή πριν θεωρηθεί καθολική.
