Διόρθωση του ModuleNotFoundError στην Python

Πρακτικός οδηγός για «Διόρθωση του ModuleNotFoundError στην Python», με ασφαλή βήματα, εντολές που μπορείς να αντιγράψεις και σαφή εξήγηση των συνηθισμένων προβλημάτων.

Γρήγορη λύση

Πρακτικός οδηγός για «Διόρθωση του ModuleNotFoundError στην Python», με ασφαλή βήματα, εντολές που μπορείς να αντιγράψεις και σαφή εξήγηση των συνηθισμένων προβλημάτων.

Ο οδηγός εστιάζει στη συγκεκριμένη περίπτωση και ξεκινά από τα πιο πιθανά αίτια, ώστε να μη γίνουν άσκοπες αλλαγές.

Εστίασε στην πρώτη σαφή ένδειξη και χρησιμοποίησε το αποτέλεσμα για να επιλέξεις την επόμενη μικρή διόρθωση, αντί να επανεγκαταστήσεις τα πάντα.

Τι να ελέγξεις

  • Διάβασε την πρώτη γραμμή που αναφέρει συγκεκριμένο αρχείο, πακέτο, θύρα, λειτουργική μονάδα, δικαίωμα ή διαδρομή.
  • Διάβασε ολόκληρο το μήνυμα και σημείωσε την πρώτη συγκεκριμένη αναφορά σε αρχείο, πακέτο, module, θύρα, δικαίωμα ή διαδρομή.
  • Αν η πρώτη εντολή εμφανίσει διαφορετικό σφάλμα, ακολούθησε το νέο μήνυμα αντί να επαναλαμβάνεις μηχανικά τα ίδια βήματα.

Εντολές για αντιγραφή

Αντέγραψε τις εντολές μία-μία. Άλλαξε μόνο τις ενδεικτικές τιμές, όπως `PACKAGE_NAME`, `folder_name` ή `URL`, όταν εμφανίζονται πραγματικά στην εντολή.

python - <<'PY'
import sys
print(sys.executable)
print(sys.path[:3])
PY
python -m pip install MODULE_NAME
python -c "import MODULE_NAME; print('ok')"

Πώς να διαβάσεις το αποτέλεσμα

  1. python - <<'PY' — εκτελεί την εντολή απευθείας, ώστε να εμφανιστεί το πρώτο πλήρες μήνυμα σφάλματος.
  2. import sys — εκτελεί τον συγκεκριμένο έλεγχο· διάβασε ολόκληρο το αποτέλεσμα πριν προχωρήσεις.
  3. print(sys.executable) — εκτελεί τον συγκεκριμένο έλεγχο· διάβασε ολόκληρο το αποτέλεσμα πριν προχωρήσεις.
  4. print(sys.path[:3]) — εκτελεί τον συγκεκριμένο έλεγχο· διάβασε ολόκληρο το αποτέλεσμα πριν προχωρήσεις.
  5. PY — εκτελεί τον συγκεκριμένο έλεγχο· διάβασε ολόκληρο το αποτέλεσμα πριν προχωρήσεις.
  6. python -m pip install MODULE_NAME — εγκαθιστά τη βιβλιοθήκη στο ενεργό περιβάλλον της Python.
  7. python -c "import MODULE_NAME; print('ok')" — εκτελεί την εντολή απευθείας, ώστε να εμφανιστεί το πρώτο πλήρες μήνυμα σφάλματος.

Ασφαλής σειρά ενεργειών

  1. Κράτησε ένα στιγμιότυπο οθόνης ή αντέγραψε το πλήρες αποτέλεσμα του τερματικού πριν αλλάξεις αρχεία ή ρυθμίσεις.
  2. Άλλαζε μόνο ένα πράγμα κάθε φορά και έλεγχε ξανά το αποτέλεσμα πριν συνεχίσεις.
  3. Αν αλλάξει το μήνυμα σφάλματος, διάβασε τη νέα ένδειξη· συνήθως σημαίνει ότι το προηγούμενο βήμα διορθώθηκε.

Συνηθισμένα λάθη

  • Εκτέλεση της εντολής από λάθος φάκελο, ενώ το έργο ή το αρχείο βρίσκεται αλλού.
  • Χρήση οδηγιών για Linux σε υπολογιστή που αγνοούν τις διαδρομές και τους περιορισμούς αποθήκευσης του Android.
  • Κλείσιμο του Termux πριν αποθηκευτεί το πλήρες μήνυμα που εξηγεί το πρόβλημα.
