# Termux compatibility

The Academy is designed exclusively for Android with Termux.

| Capability | Supported |
|---|---:|
| English and Greek theory lessons | Yes |
| Shell and file laboratories | Yes |
| Python automation laboratories | Yes |
| Local sample evidence | Yes |
| Device-local progress | Yes |
| Root access | Not required |
| Desktop-only compiled programs | Not included |

The website teaches. Commands, programs, evidence and progress remain in the learner's Termux environment.
