Frequently Asked Questions

Project-only answers for DedSec Project. Technical Termux errors, ideas, tips, and script guides moved to Assistance so each topic has its own page, while the Store covers support and sponsor tiers.

Project Basics

What is the DedSec Project?

DedSec Project is a phone-first Termux toolkit and website ecosystem for learning, organizing scripts, checking links/files, exploring OSINT awareness, and solving Android/Termux workflow problems in a legal and responsible way.

Who created it?

The project was created by dedsec1121fk and is maintained around the public website, GitHub repository, guides, support pages, and sponsor-only extras.

Is DedSec Project only for programmers?

No. It is designed for people who want to learn Termux and solve real digital problems from an Android phone. Beginners should start from the Installation Guide, then Learn About The Tools, then Assistance.

Does it require root?

Most of the project is built for no-root Android usage through Termux. If a tool ever needs a special permission, it should explain it before use.

Website Navigation

Where should a new user start?

Start from the main page, open Guide For Installation, read Learn About The Tools, then use Assistance when you hit a specific Termux or DedSec problem.

What is Assistance?

Assistance replaced the old assistant chat. It is a set of standalone SEO-friendly help pages for Termux setup, storage permission, Python modules, pip errors, GitHub clone, unzip, updates, and broken installs.

Why is the FAQ now only about the project?

Project questions stay here. Technical Termux troubleshooting moved to Assistance so each problem has its own focused page that users and search engines can understand better.

Where can I find direct support?

Use the Store for direct chat support, setup help, repair help, custom scripts, ButSystem re-branding, and other services. Use Contact & Credits for available contact options.

Tools, Safety & Use

Are the tools meant for illegal hacking?

No. The project should be used for learning, privacy awareness, authorized testing, diagnostics, and personal workflow improvement. Do not use any tool against systems or accounts you do not own or have permission to test.

Where can I learn what each tool does?

Open Learn About The Tools. That page explains the tools and helps you decide what to run before you touch Termux commands.

What is ButSystem.py?

ButSystem.py is presented as an exclusive DedSec Project offer with its own page. Open the ButSystem page to understand the concept, access model, and related services.

Is the project bilingual?

Yes. The website supports English and Greek with a language switcher, and new Assistance pages include both English and Greek text.

Sponsors & Store

What are sponsors-only tools?

Sponsors-only tools are extra scripts or resources available through the project’s sponsor tiers when access is active. The Store and sponsor links explain the current access paths.

What can I buy from the Store?

The Store contains direct chat support, setup help, repair help, custom scripts, ButSystem re-branding, portfolio/CV website services, and sponsor-related options.

What should I send when asking for repair help?

Send a clear screenshot of the error, the command you ran, the folder shown by pwd, and what you expected to happen. This makes support faster.

Does the FAQ replace paid support?

No. The FAQ and Assistance guides are free self-help. Paid support is for users who want someone to handle the issue directly or explain the fix personally.

Looking for Termux error fixes?

Use the Assistance for storage permission, ModuleNotFoundError, pip errors, GitHub clone, unzip, Downloads path, updates, and broken DedSec installs. Use the Store when you want direct help instead of troubleshooting alone.
