# Attribution

The DedSec Smartphone Academy curriculum is adapted from the HackTheBasics.gr educational project and its later bilingual academy build. The original course repository was created by `anfrann25`. The DedSec integration changes the presentation, branding, navigation, device guidance, local companion paths, and website architecture while retaining educational acknowledgement of the source material.

The academy is intended only for legal, authorized, defensive, and educational use. Practical exercises should run against local files, local virtual machines, intentionally vulnerable training targets, or systems for which the learner has explicit permission.
