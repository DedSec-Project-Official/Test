# Official reference sources

The Smartphone Academy uses primary platform documentation for facts that can change between Android releases.

- Android security overview and application sandbox — Android Open Source Project
- Android security bulletins — Android Open Source Project
- Android permissions — Android Developers
- Android device and app compatibility — Android Developers and Google Play Help
- APK publishing, signing and alternative distribution — Android Developers
- Android updates, Play Protect and privacy controls — Google Support
- Termux installation and package information — official Termux GitHub organization

Individual lessons link to the relevant official page. Learners should verify version-specific steps against the documentation for their phone and Android release.
