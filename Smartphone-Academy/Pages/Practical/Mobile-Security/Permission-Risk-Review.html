Review App Permission Risk

Assess a fictional permission set against the app features it claims to provide.

3 hoursAndroid · Termux

Mission

Assess a fictional permission set against the app features it claims to provide.

Required work

  1. Map each permission to a claimed feature
  2. Identify permissions with no clear justification
  3. Separate runtime permissions from special access
  4. Recommend a minimum-access configuration

Evidence to produce

A permission decision table classifying required, optional, excessive and special access.

Quality checks

The result must identify its source data, separate observation from assumption, preserve supplied originals, and explain any limitation or uncertain conclusion.

Prepare the lab

Run these commands inside the Smartphone Academy folder in Termux.

python Smartphone-Academy.py prepare permission-risk-review
cd ~/.dedsec-smartphone-academy/workspaces/permission-risk-review
python Smartphone-Academy.py check permission-risk-review
python Smartphone-Academy.py complete permission-risk-review

Local and defensive

Use only the supplied fictional samples or your own device data that you deliberately choose to inspect.
