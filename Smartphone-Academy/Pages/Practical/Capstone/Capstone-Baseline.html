Capstone: Establish the Baseline

Create a complete, privacy-aware baseline of the supplied fictional Android and Termux workspace.

4h practical labAndroid · Termux
OBJECTIVE

Create a complete, privacy-aware baseline of the supplied fictional Android and Termux workspace.

TIME PLAN

Prepare 30m · Build 150m · Verify 40m · Document 20m

Working boundary

Work only inside the folder created by Smartphone-Academy.py prepare capstone-baseline. Use the supplied samples or systems you personally administer.

Prepare the Termux workspace

Open Termux in the Academy root and prepare this lab with the local companion. It creates safe samples, notes and evidence files under your Termux account.

Android + Termuxpython Smartphone-Academy.py prepare capstone-baselineNo root. Use the supplied files and keep the workspace under $HOME.

Practical mission

  1. Prepare the capstone workspace and verify source hashes.
  2. Collect host, process, service and network summaries.
  3. Document normal application behavior from the scenario.
  4. Package the baseline with an index and integrity checksum.
EVIDENCE TO PRODUCE

A baseline pack containing inventory, hashes, services, network state and assumptions.

Quality gate

The deliverable states a clear scope and date for Capstone: Establish the Baseline.
A second learner can reproduce the commands and paths.
Original samples remain unchanged and verifiable.
Limitations are recorded beside the conclusions.

Analyst reflection

Which result from “Package the baseline with an index and integrity checksum” would need more evidence before it could support an operational decision?

Complete in Termux

After checking the evidence, run python Smartphone-Academy.py complete capstone-baseline. Progress is stored locally in the Termux home directory.

Practice locally

Read the lesson here, then run the required commands and programs inside Termux on your Android device.

Safety boundary
