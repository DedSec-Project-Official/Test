Verify a Backup and Restore Plan

Inspect a fictional phone backup plan and test sample restores without exposing personal data.

3 hoursAndroid · Termux

Mission

Inspect a fictional phone backup plan and test sample restores without exposing personal data.

Required work

  1. Map contacts, photos, documents, messages, app data and credentials
  2. Identify items excluded by each backup method
  3. Hash sample files before and after restore
  4. Document recovery steps if the original phone is unavailable

Evidence to produce

A backup coverage map plus verified restore evidence for selected file types.

Quality checks

The result must identify its source data, separate observation from assumption, preserve supplied originals, and explain any limitation or uncertain conclusion.

Prepare the lab

Run these commands inside the Smartphone Academy folder in Termux.

python Smartphone-Academy.py prepare backup-restore-verification
cd ~/.dedsec-smartphone-academy/workspaces/backup-restore-verification
python Smartphone-Academy.py check backup-restore-verification
python Smartphone-Academy.py complete backup-restore-verification

Local and defensive

Use only the supplied fictional samples or your own device data that you deliberately choose to inspect.
