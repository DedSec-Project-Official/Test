Analyze Thermal Throttling

Correlate supplied temperature, frequency, frame-time and charging observations.

3 hoursAndroid · Termux

Mission

Correlate supplied temperature, frequency, frame-time and charging observations.

Required work

  1. Plot or tabulate temperature over time.
  2. Mark workload and charging changes.
  3. Identify sustained performance reduction.
  4. Recommend cooling and workload changes without risky modifications.

Evidence to produce

A thermal report that separates normal warming, throttling and unsafe conditions.

Quality checks

The result must identify its source data, separate observation from assumption, preserve supplied originals, and explain any limitation or uncertain conclusion.

Prepare the lab

Run these commands inside the Smartphone Academy folder in Termux.

python Smartphone-Academy.py prepare thermal-performance
cd ~/.dedsec-smartphone-academy/workspaces/thermal-performance
python Smartphone-Academy.py check thermal-performance
python Smartphone-Academy.py complete thermal-performance

Local and defensive

Use only the supplied fictional samples or your own device data that you deliberately choose to inspect.
