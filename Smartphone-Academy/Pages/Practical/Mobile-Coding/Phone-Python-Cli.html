Build a Safe Python CLI on a Phone

Create a read-only file inventory tool with JSON output, validation and useful exit codes.

3 hoursAndroid · Termux

Mission

Create a read-only file inventory tool with JSON output, validation and useful exit codes.

Required work

  1. Parse arguments with clear help.
  2. Reject missing or unsafe paths.
  3. Produce deterministic JSON.
  4. Test success, empty and permission-error cases.

Evidence to produce

A tested CLI, sample output and failure-case report.

Quality checks

The result must name its sources, separate observation from assumption, preserve originals and explain limitations.

Prepare the lab

Run these commands inside the Smartphone Academy folder in Termux.

python Smartphone-Academy.py prepare phone-python-cli
cd ~/.dedsec-smartphone-academy/workspaces/phone-python-cli
python Smartphone-Academy.py check phone-python-cli
python Smartphone-Academy.py complete phone-python-cli

Local and safe

Use only the supplied fictional samples or data from your own device.
